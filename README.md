# beam-fem-deflection-analyzer
Interactive [![Live demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-65d6e8)](https://raghav1822.github.io/beam-fem-deflection-analyzer/)

Interactive structural digital twin that animates a proof-load vehicle across a simply supported bridge beam. It combines live FEM response, sensor deflection data, stiffness damage localization, peak stress, structural health, and a replayable load-test scan.

## Run locally

```bash
npm test
npm run serve
```
